# Security Policy

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the Security tab of https://github.com/tysmmsy/mail-link-guard, not in a public issue.

Include the extension version, the Chrome version, and the steps to reproduce. Do not include real email contents or personal data; replace URLs with `example.com` where possible.

Reports are especially welcome for anything that could send data off the device, let the mail page read what the dialog shows, or let a crafted link or import file bypass or slow down the check.

Fixes are released as a new version. The project is maintained by one person in spare time, so there is no guaranteed response time.

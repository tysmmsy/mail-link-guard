# Mail Link Guard

[English](README.md)

Mail Link Guardは、Webメールでリンクをクリックしたときに一度止めて、開く前に実際の行き先を表示するChrome拡張機能です。
MIT Licenseで公開しているオープンソースソフトウェアです。
自分で登録したブロックリストの行き先は開きません。
保存するのはオンとオフの設定とブロックリストだけで、外部とは通信しません。

![確認ダイアログ](release-assets/confirm.png)

## できること

- メール本文のリンクをクリックすると、開く前にダイアログでリンクの文字、行き先のドメイン、URL全体を表示します。似せたドメインは、`xn--`の形と並べて実際の文字（例：`αmazon.co.jp`）でも表示します。
- 当てはまる場合だけ、形式上の注意点を表示します。対象は、リンクの文字と行き先のドメインの食い違い、暗号化されていないHTTP、IPアドレスの直接指定、Punycodeのドメイン、短縮URL、URLの「@」より前の文字です。「安全」とは判定しません。
- Googleのリダイレクト（google.com/url）とMicrosoftのSafe Linksを外して、実際の行き先を表示します。開くときは元のURLを経由します。
- ダイアログの「ブロックする範囲」の欄で、ドメイン全体かそのURLだけを選び、赤い「ブロックリストに追加」を押すと、メモ付きで登録できます。登録した行き先は、次のクリックから開きません。リダイレクトを経由するリンクや、メール本文の外のリンクも対象で、ダイアログに「開く」ボタンは出ません。
- 設定画面で、ブロックリストの一覧、絞り込み、追加、削除、JSONのインポートとエクスポートができます。

動くのは`https://mail.google.com/*`だけです。

![ブロックした行き先](release-assets/blocked.png)

## ブロックリストに登録できるもの

| 種類 | 対象 | 例 |
|---|---|---|
| ドメイン | そのドメインとサブドメイン | `evil.example` |
| URL | その文字列で始まるURL（`#`以降は無視） | `https://cdn.example.com/phish/` |
| ワイルドカード | `*`は任意の文字列に当たります。`/`を含まなければドメイン、`://`を含めばURL全体、それ以外はドメインとパスと照合します。大文字と小文字は区別しません。 | `*.amaz0n.*`、`*α*`、`*/wp-admin/*` |
| 正規表現 | JavaScriptの正規表現を、URL全体と大文字と小文字を区別せずに照合します。500文字までです。 | `^https?://[^/]*paypa[l1]\.` |

ワイルドカードと正規表現は、ブラウザが持っている形（`xn--mazon-c9d.co.jp`）と、ドメインをUnicodeに戻した形（`αmazon.co.jp`）の両方と照合します。
そのため、似せた文字をそのままパターンに書けます。
たとえば`*α*`を登録すると、ギリシャ文字のαを含むドメインをすべて止めます。

新しく入れたときは、「疑わしきは止める」考え方で次の3件が登録されています。
どれも、ラテン文字に見せかけたドメインを対象にしています。
ほかの項目と同じように削除できます。

| 止めるもの | 例 |
|---|---|
| ギリシャ文字で「amazon」に似せたドメイン | `αmazon.co.jp`、`amazοn.com` |
| 1つの単語の中で、ラテン文字とギリシャ文字やキリル文字が混ざったドメイン | `pаypal.com`（キリル文字のа）、`gοogle.com`（ギリシャ文字のο） |
| ラテン文字に見えるギリシャ文字やキリル文字だけで書かれたドメイン | `аррӏе.com`（appleに見えるが、ラテン文字を含まない） |

ふつうのロシア語、ギリシャ語、日本語、アクセント付きのドメイン（`яндекс.рф`、`αλφα.gr`、`例え.jp`、`café.fr`）は止めません。
文字の種類が混ざっておらず、ラテン文字に見えない文字を含むためです。
正規表現の中身は[src/core/blocklist.ts](src/core/blocklist.ts)の`DEFAULT_PATTERNS`にあります。

この3件を登録するのは最初に入れたときだけです。削除した項目が、更新で戻ることはありません。

正規表現はメール本文のリンクをクリックするたびに実行されます。
`(a+)+`のような繰り返しを重ねた書き方は、URLによっては照合に時間がかかります。
照合の前にURLを4,096文字までに切っていますが、パターンはなるべく単純に書いてください。
他の人から受け取ったファイルをインポートするときは、正規表現の中身を確かめてください。

## プライバシー

| `chrome.storage.local`に保存するもの | 中身 |
|---|---|
| `enabled` | リンクを確認するかどうか |
| `blocklist` | 各項目の種類、値、任意のメモ、登録日 |

これ以外は保存しません。
組織が強制する設定は、Chromeのポリシーとして読み取り専用の`chrome.storage.managed`に届きます。拡張機能はそれをどこにも書き出しません。
クリックしたリンクのURLと文字は、ダイアログを表示している間だけメモリに置きます。
メールの内容、閲覧の履歴、クリックの履歴は保存しません。

- 外部と通信しません。コードには`fetch`、`XMLHttpRequest`、`WebSocket`、`EventSource`、`sendBeacon`がありません。拡張機能のページのContent Security Policyでは`connect-src 'none'`を指定しています。リンクの確認、ブロック、登録の操作中に通信が1件でも起きると失敗するe2eテストもあります。
- 同期しません。`chrome.storage.local`は端末の中にだけ置かれ、Chromeの同期の対象外です。
- メールのページから見えません。ダイアログは閉じたShadow DOMの中にあり、ダイアログで打った文字やキー操作は、メールのページのスクリプトに届く前に止めます。
- データが端末の外に出るのは、利用者が自分でブロックリストをファイルにエクスポートしたときだけです。

詳しくは[PRIVACY.md](PRIVACY.md)を参照してください。

## 権限

| 権限 | 理由 |
|---|---|
| `https://mail.google.com/*`でのコンテンツスクリプト | メールのリンクのクリックを止めるため |
| `storage` | オンとオフの設定とブロックリストを端末に保存するため |

## できないこと

- 表示するのは最初の行き先だけです。その先のリダイレクト（短縮URLの最終的な行き先を含む）は追いません。
- 右クリックメニューの「新しいタブで開く」と、リンクのドラッグは止められません。
- 形式上の注意点は手がかりにすぎません。危険なリンクの多くは、どれにも当てはまりません。
- メール本文の判定は、本文の入れ物に付いているクラス名に頼っています。メールの画面の作りが変わると、拡張機能を更新するまで本文のリンクは確認なしで開きます。ブロックリストの行き先は、その間もページ全体で止めます。

## 言語

画面の言語は、Chromeの表示言語に合わせて切り替わります。
対応しているのは、英語、日本語、簡体字中国語、繁体字中国語、韓国語、スペイン語、ブラジルポルトガル語、フランス語、ドイツ語、イタリア語、ロシア語です。それ以外の言語では英語で表示します。
英語と日本語以外は機械の支援で訳したもので、修正を歓迎します。
翻訳の追加と修正の方法は[CONTRIBUTING.md](CONTRIBUTING.md)に書いています。

## 組織への展開

管理者は、Chromeのポリシー（Google管理コンソール、Windowsのグループポリシー、macOSの構成プロファイル）で設定を強制できます。
リンクの確認を常にオンにする、利用者が削除できないブロックリストを配る、利用者自身の登録を止める、の3つです。
詳しくは[docs/enterprise.ja.md](docs/enterprise.ja.md)を参照してください。

## デザイン

設定画面とポップアップは、[shadcn/ui](https://ui.shadcn.com/)のコンポーネント（React、Radix UI、Tailwind CSS）で作り、クラシックMac OSのPlatinumの見た目に合わせています。
灰色のウィンドウ、縞模様の題名、立体的なボタンで、アニメーションはありません。
メールのページに出すダイアログは、同じ見た目をフレームワークなしのDOMで作っています。
そのため、メールのページで余計なライブラリを読み込まず、クリックと同じフレームでダイアログを表示します。

## 開発

Node.js 24とpnpmが必要です。

```sh
pnpm install
pnpm build          # dist/ に展開済みの拡張機能を書き出す
pnpm test           # 単体テスト
pnpm test:e2e       # 拡張機能をChromiumに読み込み、メールのページを模したページで動作を確かめる
pnpm lint
pnpm typecheck
pnpm package        # release/mail-link-guard-<version>.zip を作る
pnpm screenshots    # release/screenshots/ に画面を書き出す
pnpm icons          # scripts/make-icons.ts から static/icons/ を描き直す
```

自分のChromeで使うときは、`chrome://extensions`でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で`dist/`を選びます。
`pnpm build`をやり直したら、拡張機能のカードの再読み込みボタンを押します。
e2eテストの前に、一度だけ`pnpm exec playwright install chromium`を実行してください。

メールのページとバックグラウンドで動くスクリプトは圧縮（minify）していないので、メールの横で動くコードを書いたままの形で読めます。
設定画面とポップアップは、ポップアップを速く開くために圧縮しています。
